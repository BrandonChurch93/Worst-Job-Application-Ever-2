# The Worst Job Application Ever

**Status: planning. Do not build from this repo yet.** The build kit is not complete. No build task may start until `AGENTS.md` exists at the repo root and `references/approved/` holds the approved images.

A comedy told as a job application. A cheerful careers page leads into a five-step application that fights back at every step: turrets guarding the keyboard, a shredder that eats the resume, fields that open into the wrong machine, a full arcade pinball machine as the skills assessment, and a Submit button that turns into a boss. The applicant is a mouse cursor with the body language of a cartoon character. It is rejected.

It is one real website, delivered two ways:

- **The film.** The site plays itself start to finish and is recorded as a showcase for Perplexity Computer.
- **The live site.** A visitor on Brandon Church's portfolio does the application with their own mouse.

Everything on screen is a real web page made of real things: ceramic, aluminum, glass and orange plastic, seen straight on, lit by one light. The motion is cartoon. The picture is real.
